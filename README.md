# Волейбол ойындарына онлайн тіркелу

Laravel API (`api/`) + React/Vite (`frontend/`).

- **Қатысушылар** (аккаунтсыз): күнді таңдап, сол күнгі ойындарды көреді, аты мен WhatsApp нөмірі арқылы тіркеледі.
- **Ұйымдастырушылар** (аккаунтпен): ойын қосады/өзгертеді/өшіреді, қатысушыларды көреді, қолмен қосады, төлемді қолмен белгілейді.

## Құрылым

```
api/        Laravel жобасы (API, миграциялар, seeder)
frontend/   React (Vite) қосымшасы
```

## 1. Backend (`api/`)

Талап: PHP 8.3+, Composer. Дерекқор әдепкіде SQLite (`.env.example` ішінде).

```bash
cd api
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate:fresh --seed   # кестелер + 2 демо ұйымдастырушы + 4 үлгі ойын
php artisan serve                  # http://localhost:8000
```

`.env` ішінде **`APP_TIMEZONE`** міндетті түрде ойындар өтетін жердің уақыт белдеуі болуы керек (`.env.example` ішінде `Asia/Almaty` қойылған; Бішкек үшін `Asia/Bishkek`). Қате болса, сервер "бүгінді" басқа күн деп есептеп, ойындар ауысып кетеді. Өзгерткеннен кейін `php artisan config:clear`.

**Демо ұйымдастырушылар** (құпия сөз екеуінде де `password`): `erlan@example.com`, `aigerim@example.com`

Тексеру: http://localhost:8000/api/games

## 2. Frontend (`frontend/`)

Талап: Node.js 18+.

```bash
cd frontend
cp .env.example .env               # API мекенжайы: VITE_API_URL=http://localhost:8000/api
npm install
npm run dev                        # http://localhost:5173
```

Беттер:

| Мекенжай | Не |
|----------|----|
| `/` | Ойындар (күн таңдағышымен: бүгін және алдағы 6 күн), тіркелу |
| `/games/:id` | Бір ойынның беті (бөлісуге арналған сілтеме), тіркелу |
| `/organizer/login` | Ұйымдастырушы кіруі / аккаунт ашу |
| `/organizer` | Менің ойындарым (алдағы және өткен) |
| `/organizer/games/new` | Ойын қосу |
| `/organizer/games/:id` | Қатысушылар, төлем белгісі, қолмен қосу, өшіру |
| `/organizer/games/:id/edit` | Ойынды өзгерту |

Production-да сайтты қызмет ететін сервер барлық жолды `index.html`-ге бағыттауы керек (SPA fallback), әйтпесе `/organizer` не `/games/12` сияқты бетті жаңартқанда (немесе сілтемемен ашқанда) 404 шығады.

## Ұйымдастырушы қалай жұмыс істейді

1. Email және құпия сөзбен аккаунт ашады немесе кіреді (Laravel Sanctum токені).
2. «Ойын қосу»: формат, күні, уақыты, ұзақтығы, зал, мекенжай, баға, төлем мәліметі (мысалы Kaspi нөмірі, міндетті емес), командалар саны. Орын саны автоматты: командалар × 6 (3 команда = 18, 2 команда = 12). Ұйымдастырушы есімі аккаунттан алынады. «Апта сайын қайталау» өрісі арқылы бірден 12 аптаға дейін бірдей ойын қосуға болады (барлығы бір транзакцияда). Бірдей ойынды (сол күн, уақыт, зал) қайта қосуға әдейі тыйым салынбайды: бір залда бірнеше алаң болуы мүмкін.
3. Ойынды ашса, қатысушылар тізімі көрінеді: аты, телефоны (WhatsApp сілтемесімен), жынысы, төлем статусы. «Төленбеді/Төленді» батырмасы төлемді қолмен белгілейді. Төлемі жоқ қатысушының нөмірін басса, WhatsApp-та төлем мәліметі бар дайын хабарлама ашылады («төлемді еске салу»). Ойыншы тіркелгенде төлем мәліметін сәтті экранда көреді (ашық тізімде көрсетілмейді); төлемді ұйымдастырушы чек бойынша қолмен растайды. Жоғарыда тіркелген, төленген адам саны және жиналған сома көрінеді.
   - **Төлем мерзімі**: ойынды құрғанда «Ойынға N сағат қалғанға дейін» таңдауға болады (`payment_deadline_hours`, 1–168). Мерзім ойыншыға тіркелгеннен кейін және WhatsApp еске салуында көрсетіледі; мерзімі өткен төленбегендер қызылмен белгіленеді. Орын өздігінен босамайды.
   - **Тегін ойын**: «Тегін ойын» қосқышы бағаны `0` етеді; төлем өрістері, төлем статусы мен сомалар жасырылады, карточкада «Тегін» көрсетіледі.
   - **Бас тарту (аккаунтсыз)**: ойыншы тіркелгенде жеке сілтеме `/cancel/<token>` алады. Сілтемемен ойынға **3 сағат қалғанға дейін** бас тартуға болады (`Game::CANCEL_HOURS_BEFORE`); одан кейін ұйымдастырушыға WhatsApp-та жазады. Төлемі бар адам бас тартса, жазба «Бас тартқандар» бөлімінде «Төлемді қайтару керек» болып қалады.
   - **Күту тізімі**: орын (жалпы немесе жыныс лимиті бойынша) бітсе, ойыншы «Күту тізімі» арқылы жазылады. Орын босағанда ұйымдастырушы тізімнен «Ойынға қосу» батырмасын басады (өздігінен көшпейді) немесе WhatsApp-та жазады.
4. Қатысушыны қолмен қоса алады (мысалы, жазылмай келген адам) немесе тізімнен шығара алады. Орын және жыныс лимиттері қолмен қосқанда да тексеріледі.
5. Ойынды өзгертеді немесе өшіреді. Тіркелген адамдар жаңа орын санына немесе форматқа сыймаса, өзгерту қабылданбайды. «Көшіру» батырмасы ойынның мәліметтерін жаңа ойын формасына көшіреді (күні келесі аптаға ауысады, қатысушылар көшірілмейді).
6. Ұйымдастырушы тек өз ойындарын көреді және өзгертеді (басқа біреудікі 403 қайтарады).
7. Әр ойынның жеке беті бар: `/games/:id`. Ұйымдастырушы ойын бетіндегі «Ойынға сілтеме» бөлімінен сілтемені көшіреді немесе «WhatsApp-қа жіберу» арқылы дайын хабарламамен (уақыты, залы, бағасы, сілтеме) топқа жібереді. Ойыншы карточкадағы «Бөлісу» батырмасын қолданады. Ескерту: сайт браузерде құрылатындықтан (SPA), WhatsApp-та сілтеменің суретті превьюі шықпайды, мәтіннің өзі хабарламаға қосылады.

## API

Қонақтар:

| Әдіс | URL | Сипаттама |
|------|-----|-----------|
| GET  | `/api/games` | Ойындар (`?date=YYYY-MM-DD`; берілмесе сервердің бүгіні) |
| GET  | `/api/games/{id}` | Бір ойын |
| POST | `/api/games/{id}/register` | Тіркелу: `name`, `phone`, `gender` (`male`/`female`), `waitlist` (міндетті емес: орын жоқ болса, күту тізіміне жазу; орын жоқта және `waitlist` жоқта жауап 409 + `full: true`). Жауапта `status` (`active`/`waitlist`), `cancel_token`, `waitlist_position`, `payment_info`, `payment_deadline` (`YYYY-MM-DD HH:MM`) және `is_free` қайтады (тегін ойында төлем мәліметі `null`) |
| GET | `/api/registrations/{token}` | Ойыншының өз тіркеуі: `status` (`active`/`waitlist`/`cancelled`), `can_cancel`, `cancel_deadline`, ойын мәліметі |
| POST | `/api/registrations/{token}/cancel` | Бас тарту (ойынға 3 сағат қалғанға дейін; күту тізімінен — ойын басталғанға дейін) |

Аккаунт:

| Әдіс | URL | Сипаттама |
|------|-----|-----------|
| POST | `/api/auth/register` | `name`, `email`, `password` (≥ 8 таңба) → `token`, `user` |
| POST | `/api/auth/login` | `email`, `password` → `token`, `user` |
| GET  | `/api/auth/me` | Қазіргі қолданушы |
| POST | `/api/auth/logout` | Токенді өшіреді |

Ұйымдастырушы (`Authorization: Bearer <token>` керек):

| Әдіс | URL | Сипаттама |
|------|-----|-----------|
| GET    | `/api/organizer/games` | Өз ойындары |
| POST   | `/api/organizer/games` | Ойын қосу. `payment_info` (міндетті емес, ≤ 255 таңба). `payment_deadline_hours` (міндетті емес, 1–168). `price: 0` — тегін ойын (төлем өрістері өздігінен тазаланады). `repeat_weeks` (0–12, міндетті емес): қосымша қанша апта қайталау. Жауап: `data` — бірінші ойын, `meta.created` — қосылған ойын саны |
| GET    | `/api/organizer/games/{id}` | Ойын + қатысушылар |
| PUT    | `/api/organizer/games/{id}` | Өзгерту |
| DELETE | `/api/organizer/games/{id}` | Өшіру |
| POST   | `/api/organizer/games/{id}/registrations` | Қатысушыны қолмен қосу |
| PATCH  | `/api/organizer/games/{id}/registrations/{rid}` | Төлем белгісі: `{"paid": true}` |
| POST   | `/api/organizer/games/{id}/registrations/{rid}/promote` | Күту тізімінен ойынға қосу (орын бар болса) |
| DELETE | `/api/organizer/games/{id}/registrations/{rid}` | Қатысушыны шығару |

## Ойын форматтары

| Мән | Мағынасы | Жыныс лимиті |
|-----|----------|--------------|
| `mixed` | Аралас | шектеу жоқ |
| `girls` | Тек қыздар | тек қыз |
| `boys`  | Тек ұлдар | тек ұл |
| `4_2`   | 4 ұл / 2 қыз | әр командаға 4 ұл, 2 қыз |
| `2_4`   | 2 ұл / 4 қыз | әр командаға 2 ұл, 4 қыз |

**WhatsApp нөмірі.** Нөмір қатаң тексеріледі және `+77011234567` (E.164) пішіміне келтіріледі: `+7 701…`, `8 701…`, `7701…` бір нөмір болып саналады. Қазақстан ұялы нөмірлері (`+7 70X`, `74X`–`77X`), Ресей ұялы нөмірлері (`+7 9XX`) және `+` пен ел коды бар халықаралық нөмірлер қабылданады; қалалық нөмірлер (мысалы Атырау `+7 7122…`, Алматы `+7 727…`) қабылданбайды. Ұйымдастырушы тізімінде нөмір `wa.me` сілтемесі болып шығады.
Ереже екі жерде бірдей болуы керек: `api/app/Support/PhoneNumber.php` (сервер) және `frontend/src/phone.js` (браузер). Біреуін өзгертсеңіз, екіншісін де өзгертіңіз. Серверде `api/tests/Unit/PhoneNumberTest.php` тесті бар.
Ескерту: бұл пішімді тексеру, нөмірде WhatsApp *шынымен бар екенін* растау емес (ол үшін OTP-растау керек).

Бір нөмір бір ойынға бір рет қана тіркеледі; соңғы орынға екі адам бірдей тіркелмеуі үшін транзакция мен `lockForUpdate` қолданылған.

## Әлі жасалмаған

- Онлайн төлем (Kaspi / карта): қазір төлемді ұйымдастырушы қолмен белгілейді
- WhatsApp нөмірін растау (OTP): WhatsApp Business Cloud API арқылы код жіберу
- Құпия сөзді қалпына келтіру
- Қатысушының тіркеуден өзі бас тартуы
